# МосНейро

Учебное веб-приложение для расчётов, работы с формулами и учебными материалами.
Реализовано как единый статический HTML-файл (`index.html`) без серверной части
и без сборки — открывается прямо в браузере.

## Возможности

- Математика
  - Калькулятор выражений с собственным парсером (без `eval`):
    `+ − * / ^ %`, скобки, `sin`, `cos`, `tan`, `asin`, `acos`, `atan`,
    `sqrt`, `abs`, `ln`, `log`, `exp`, `factorial`, константы `pi` и `e`.
    Тригонометрия работает в градусах.
  - Конвертер единиц: длина, масса, время, скорость, площадь, объём,
    энергия, давление.
  - Расчёт по формулам: площадь круга и треугольника, теорема Пифагора,
    процент от числа, квадратное уравнение, объём шара.

- Физика
  - Справочник формул по разделам: кинематика, динамика, электричество,
    работа и энергия, плотность и давление, теплота.
  - Подстановка значений и автоматический расчёт результата с единицами.
  - Разбор простых текстовых задач на путь/время/скорость.

- Поиск в сети
  - Поиск статей через открытый API Википедии (нужен интернет).

- Мои документы
  - Загрузка текстовых файлов: `.txt`, `.md`, `.csv`, `.json`, `.html`
    (до 2 МБ каждый) и полнотекстовый поиск по их содержимому.

- Библиотека
  - Личные заметки с поиском и удалением.

- Оформление отчёта
  - Генерация титульного листа и основы учебной работы в виде HTML-файла,
    который открывается в Word и сохраняется в DOCX.

- Настройки
  - Экспорт резервной копии данных в JSON.
  - Полная очистка сохранённых данных.

## Стек

- Чистый HTML + CSS + JavaScript (ES2017+).
- Без фреймворков, без сборщиков, без зависимостей.
- Хранение данных — `localStorage` (ключи с префиксом `mosneiro_`).

## Структура проекта

mos_neiro/
└── index.html

## Запуск

1. Склонируйте репозиторий или скачайте `index.html`.
2. Откройте файл в современном браузере (Chrome, Firefox, Edge, Safari).

Никакой установки и локального сервера не требуется.
Для работы поиска по Википедии нужен доступ в интернет.

## Хранение данных

| Ключ localStorage     | Что хранит                        |
|-----------------------|-----------------------------------|
| `mosneiro_notes`      | Массив заметок библиотеки         |
| `mosneiro_docs`       | Массив загруженных документов     |

Данные не синхронизируются между устройствами и не отправляются на сервер.
Резервную копию можно выгрузить в «Настройки → Экспортировать данные».

## Ограничения

- PDF и DOCX не читаются — поддерживаются только текстовые форматы.
- Оформление отчёта генерируется как HTML; итоговое соответствие ГОСТ
  нужно проверять по методическим требованиям учебного заведения.
- Тригонометрические функции принимают углы в градусах.
- Максимальный размер одного загружаемого файла — 2 МБ.
