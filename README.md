Учебное веб-приложение для расчётов, работы с физическими формулами и учебными материалами.
Реализовано как единый статический HTML-файл (`index.html`) — без серверной части,
без сборки и без зависимостей. Открывается прямо в браузере.

**Версия интерфейса:** 1.2 (Engineering)
**Сайт:** https://ksenianadbitova.github.io/mosneiro_web/

### Математика

- **Инженерный калькулятор** с сеткой кнопок:
  - базовые операции `+ − × ÷`, скобки, степень `x^y`, проценты;
  - функции `sin`, `cos`, `tan`, `asin`, `acos`, `atan` (в градусах),
    `sqrt`, `abs`, `ln`, `log`, `exp`;
  - факториал `n!`, константы `π` и `e`;
  - память `ans` — подстановка результата последнего вычисления;
  - кнопки `C` и `⌫`, защита от деления на ноль и неверных выражений;
  - собственный математический парсер, **без `eval` и `Function`**.
- **Конвертер величин:** длина, масса, время, скорость, площадь, объём,
  энергия, давление.
- **Готовые формулы:** площадь круга и треугольника, теорема Пифагора,
  процент от числа, квадратное уравнение, объём шара.

### Физика

- **Справочник формул** по разделам:
  - кинематика (скорость, путь, ускорение);
  - динамика (сила, импульс);
  - электричество (закон Ома, напряжение, мощность);
  - работа и энергия (работа, кинетическая и потенциальная энергия);
  - плотность и давление;
  - теплота.
- **Расчёт по формулам** с автоматической проверкой знаменателя и единиц.
- **Разбор задач:** умный парсер определяет формулы для:
  - пути/скорости/времени;
  - силы (`F = ma`);
  - работы (`A = F·s`);
  - закона Ома (`I = U/R`);
  - плотности (`ρ = m/V`).

### Поиск в сети

- Поиск справочных статей через открытый API Википедии.
- Быстрые кнопки: Python, Закон Ома, Математика.
- Требуется подключение к интернету.

### Мои документы

- Загрузка файлов с устройства: `.txt`, `.md`, `.csv`, `.json`, `.html`
  (до 2 МБ каждый).
- **Импорт из библиотеки** — сохранённые заметки и отчёты добавляются
  как документы.
- Полнотекстовый поиск по содержимому с подсветкой контекста.
- Массовая очистка.

### Библиотека

- Личные заметки и конспекты с датой создания.
- Поиск по названию и тексту.
- Удаление заметок.
- **Автопополнение**: подготовленные отчёты сохраняются сюда автоматически.

### Оформление отчёта

- Два типа оформления:
  - **ГОСТ для ВУЗов**;
  - **ГОСТ для СПО (Колледж)** — с полем «Отделение / Специальность».
- Поля: учебное заведение, кафедра/отделение, дисциплина, тема, студент,
  группа/курс, преподаватель, город, год, основной текст.
- Кнопка **«Подготовить документ»** — проверяет заполнение и сохраняет
  отчёт в библиотеку.
- Кнопка **«Скачать для Word»** — экспорт в `.html` с настройками A4,
  шрифтом Times New Roman 14 pt, полуторным интервалом и отступами
  по ГОСТ. Открывается в Word и сохраняется в DOCX.
- Встроенная справка по источникам:
  - **ГОСТ Р 7.0.100-2018** — библиографические ссылки (ВУЗ);
  - **ГОСТ 7.32-2017** — отчёты о НИР;
  - упрощённые правила для СПО.

### Настройки

- Экспорт резервной копии (JSON: заметки + документы).
- Полная очистка сохранённых данных.
- Информация о версии.

### Стек

- Чистый **HTML + CSS + JavaScript** (ES2017+).
- Без фреймворков, сборщиков и внешних зависимостей.
- Хранение данных — `localStorage` (префикс `mosneiro_`).
- Адаптивная вёрстка: десктоп, планшет, мобильный.

### Ограничения

- PDF и DOCX не читаются — поддерживаются только текстовые форматы.
- Размер одного загружаемого файла — до 2 МБ.
- Тригонометрические функции принимают углы в градусах.
- Оформление отчёта генерируется как HTML с параметрами ГОСТ; итоговое соответствие нужно сверять с методическими требованиями учебного заведения.
- Разбор задач автоматический — для сложных случаев используйте справочник формул.
